## Hard rules (from CLAUDE.md)
1. **The AI never cheats.**
   - It reads only `EmpireView` and acts only through `applyCommand`.
   - It gets no bonuses at any difficulty.
2. **Everything original.** No Master of Orion, Civilization or Babylon 5 names, art or text; the repo is public.
3. **Code adapted from Remnants of the Precursors** carries the comment `Adapted from Remnants of the Precursors (GPL-3.0)`.
4. **The engine is pure and deterministic.**
   - No `Math.random`, `Date` or DOM in `src/engine`.
   - Randomness comes only from `state.rng`.
   - State is plain JSON.
5. **Every stage ends playable**, and `npm test` must pass before pushing.
6. **Never commit API keys.**

## Tools
- `npm test`, `npm run typecheck`, `npm run dev`.
- **Balance tester:** `BALANCE=1 GAMES=18 SIZE=medium RIVALS=5 SEED0=2000 OUT=/tmp/b.json npx vitest run tools/balance.test.ts`. It runs AI-only games and records winner, victory type, wars, captures, treasuries and the final state per race. Races appear about 15–20 times per 54 games, so treat ±10% as noise.
- **Play driver:** `tools/play.test.ts`. It is git-excluded locally, so recreate it if needed: load/save a game JSON, apply commands from a JSON file, run N turns with `runAITurns(s, auto)` then `endTurn(s)`, and print only your own empire unless `PEEK=1`.
