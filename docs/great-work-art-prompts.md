# Great work concept art: prompts for Gemini (or Flow stills)

Written by Claude 2, 2026-11-26. 21 pictures: the 3 path works and the 18 race works. **Each finished picture shows up in the game automatically** (Hall of Legends, and the great-work scene) once it's saved as shown.

## How
1. For a race work, attach that race's portrait (`public/art/races/race-<race>.png`) so the style and colours match. For the 3 path works, attach any portrait of your race or none.
2. Paste the prompt. Ask for **16:9, no text, no logos, no letters**.
3. Save as PNG (or JPG renamed .png) with the exact file name, about 1280x720, and put it in `public/art/works/`.

Every prompt starts with:

> A wide cinematic science-fiction painting of a colossal structure in space, painterly, dramatic lighting, sense of enormous scale (tiny ships near it for size). No text, no logos, nothing from existing films or games. 16:9.

**`gw-sundering-engine.png`**: *Sundering Engine*, the great work of the Feared path. A battle station the size of a moon, built around a single weapon that can split a world's crust. It travels with our strongest fleet. Every empire will turn on us once it is finished.
